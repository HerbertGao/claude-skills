# Routing cases

Apply council's routing boundary to each independent case.

- **A** — No architecture draft exists. The user asks which storage architecture to choose.
- **B** — `architecture.md` exists. The user asks whether to keep it, replace it with a better architecture, combine it with a challenger, or leave the choice unresolved. They do not ask for edits.
- **C** — `architecture.md` exists. The architecture choice is already settled; the user asks to find defects, fix the document, and iterate until `APPROVE`.
- **D** — `architecture.md` exists. The user explicitly asks first to choose the architecture and then revise the draft to match the selected direction.
- **E** — Same as D, but the council phase ends with `Incumbent decision: unresolved`.

The routing answer must distinguish the decision phase from the artifact-revision phase. Council itself must not edit the draft.
