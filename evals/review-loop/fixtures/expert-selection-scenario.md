# Initial expert selection cases

The reviewed artifact is a WeChat Mini Program checkout flow. Changed files include `pages/checkout/index.wxml`, `pages/checkout/index.wxss`, and `miniprogram/app.json`. The adopted requirement explicitly requires WeChat payment integration and WCAG 2.2 AA keyboard/screen-reader behavior.

The available Agency Agents candidate summaries are:

- **WeChat Mini Program Developer** — core mission: WXML/WXSS/WXS, WeChat APIs, payments, subscription messaging, and the WeChat Mini Program ecosystem.
- **Accessibility Auditor** — core mission: WCAG auditing, assistive-technology testing, keyboard behavior, and inclusive interfaces.
- **Frontend Developer** — core mission: general web frontend implementation.
- **Software Architect** — core mission: general software architecture.
- **WeChat Official Account Specialist** — core mission: content and growth for WeChat Official Accounts, not Mini Programs.

Decide eligibility, not mandatory dispatch. The main agent is considering four legal choices: select none, select only the WeChat expert, select only the accessibility expert, or select both exact experts.

Also classify a second case in which the catalog is entirely missing.
